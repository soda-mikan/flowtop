# flowtop 0.0.1-beta

This is the first public beta of flowtop, a lightweight network-first `top` for Linux performance
testing. The release is intended for evaluation and controlled test environments.

## Highlights

- eBPF direction tracking for accepted and connected TCP sockets, with an honest `/proc` fallback
- Full-run peak-preserving graphs for TCP state, lifecycle activity, network, CPU, memory, and disk I/O
- `Accept/s`, `Connect/s`, and `Close/s` event graphs that retain short-lived connections
- Pause, reset, current/maximum values, responsive layouts, JSONL/CSV recording, and headless output
- Host, PID, and exact process-name scopes

## Security and privacy

- No packet payloads, TLS plaintext, DNS names, endpoint addresses, credentials, or command lines are
  included in the TUI or recording schema
- Shared kernel/userspace structures use explicit layout, zero initialization, reserved bytes, and
  compile-time size assertions
- Socket maps and time-series memory are bounded; direction tracking uses LRU eviction
- The loader refuses unexpected tracepoint layouts and never silently broadens privileges
- Both Cargo lockfiles passed RustSec audit with no known vulnerabilities on 2026-07-20

## Validation

- 33 workspace tests passed
- userspace Clippy passed on macOS and the `x86_64-unknown-linux-gnu` target
- BPF-target Clippy and the optimized eBPF object build passed
- eBPF load/attach smoke test passed on Debian with kernel `6.1.0-51-amd64`

## Known limitations

- This beta is not yet declared production-ready across the full kernel compatibility matrix
- Linux 5.15 and a current LTS still require verifier/load validation
- Phase 0 uses bounded `struct sock *` keys; socket-cookie migration remains planned
- PID attribution under all callback contexts, high-churn/ring-pressure behavior, and IPv6 require
  broader integration testing
- Process RX/TX payload-byte accounting and cgroup/netns scopes are not implemented

This prerelease is distributed as source code. Build it on the target Linux system with
`./scripts/build-release.sh`, then run `sudo ./scripts/test-ebpf-smoke.sh` before evaluation.
